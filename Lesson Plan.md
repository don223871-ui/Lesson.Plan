# 🎯 Lesson Plan — توضیح حرفه‌ای و دقیق

 اگر بخواهم **Lesson Plan** را واقعاً حرفه‌ای و در سطح **Teacher Training / ELT Methodology** تعریف کنم:

> **Lesson Plan فقط برنامه‌ی تدریس نیست؛ یک نقشه‌ی مهندسی‌شده برای تبدیل «هدف یادگیری» به «یادگیری قابل مشاهده» در یک زمان مشخص است.**

یعنی Lesson Plan باید دقیقاً نشان بدهد:

**Learners need → Learning Objectives → Learning Sequence → Teacher Actions → Learner Actions → Interaction → Materials → Assessment → Feedback → Learning Outcome**

---

## 1. Lesson Plan دقیقاً چه چیزی را طراحی می‌کند؟

یک Lesson Plan حرفه‌ای به این سؤال پاسخ می‌دهد:

> **در پایان این درس، زبان‌آموز دقیقاً چه چیزی را می‌داند یا می‌تواند انجام دهد که قبل از درس نمی‌توانست؟**

بنابراین نقطه‌ی شروع Lesson Plan، **Activity** نیست.

اشتباه رایج:

> «اول ببینیم چه فعالیت جالبی انجام بدهیم.»

رویکرد حرفه‌ای:

> **اول Outcome را تعیین کن، بعد فعالیت‌هایی طراحی کن که واقعاً به آن Outcome منتهی شوند.**

---

# 2. معماری اصلی Lesson Plan

می‌توانیم Lesson Plan را به‌صورت یک سیستم ببینیم:

```text
                    LEARNING NEED
                          ↓
                   LESSON OBJECTIVES
                          ↓
                  TARGET LANGUAGE / SKILL
                          ↓
                  LESSON ARCHITECTURE
                          ↓
       ┌──────────────────┼──────────────────┐
       ↓                  ↓                  ↓
   INPUT / MODEL       PRACTICE          INTERACTION
       ↓                  ↓                  ↓
       └──────────────────┼──────────────────┘
                          ↓
                    PRODUCTION / USE
                          ↓
                     ASSESSMENT
                          ↓
                     FEEDBACK
                          ↓
                LEARNING OUTCOME
```
این یعنی Lesson Plan یک زنجیره‌ی منطقی است، نه مجموعه‌ای از فعالیت‌های جداگانه.

### 3. اجزای اصلی یک Lesson Plan حرفه‌ای

| Component                   | سؤال اصلی                                     |
| --------------------------- | --------------------------------------------- |
| **Context**                 | درس در چه چارچوبی قرار دارد؟                  |
| **Learner Profile**         | چه کسانی قرار است یاد بگیرند؟                 |
| **Needs**                   | چه چیزی نیاز دارند؟                           |
| **Objectives**              | دقیقاً چه چیزی باید یاد بگیرند؟               |
| **Target Language / Skill** | موضوع زبانی یا مهارتی چیست؟                   |
| **Lead-in / Engagement**    | چگونه ذهن زبان‌آموز را وارد موضوع کنیم؟       |
| **Presentation / Exposure** | زبان‌آموز چگونه با زبان/مهارت مواجه می‌شود؟   |
| **Clarification**           | چه چیزی باید روشن و قابل فهم شود؟             |
| **Controlled Practice**     | چگونه خطا را محدود و تمرین را هدایت کنیم؟     |
| **Guided Practice**         | چگونه کنترل را کم‌کم به زبان‌آموز منتقل کنیم؟ |
| **Freer Practice**          | چگونه زبان‌آموز از دانش خود استفاده کند؟      |
| **Production / Task**       | آیا می‌تواند واقعاً از آن استفاده کند؟        |
| **Assessment**              | از کجا بفهمیم یاد گرفته است؟                  |
| **Feedback**                | چگونه عملکرد را اصلاح و تقویت کنیم؟           |
| **Timing**                  | هر مرحله چقدر زمان می‌گیرد؟                   |
| **Interaction Pattern**     | فردی، Pair، Group یا Whole Class؟             |
| **Materials**               | چه منابعی لازم است؟                           |
| **Anticipated Problems**    | چه مشکلاتی احتمالاً رخ می‌دهد؟                |
| **Solutions**               | برای هر مشکل چه راه‌حلی داریم؟                |
| **Differentiation**         | با تفاوت سطح زبان‌آموزان چه کنیم؟             |
| **Homework / Extension**    | یادگیری چگونه ادامه پیدا کند؟                 |

### 4. مهم‌ترین اصل: Alignment
این شاید مهم‌ترین مفهوم در Lesson Planning حرفه‌ای باشد:
> Alignment = هماهنگی بین Objective، Activity و Assessment

مثلاً:

#### Objective

Students will be able to use the target structure to talk about past experiences.

#### Activity

زبان‌آموزان در Pair درباره‌ی تجربه‌های واقعی خود صحبت می‌کنند و از ساختار هدف استفاده می‌کنند.

#### Assessment

معلم بررسی می‌کند آیا زبان‌آموزان واقعاً توانسته‌اند ساختار را در گفتار معنادار استفاده کنند یا نه.

این سه بخش باید به هم وصل باشند.

```
OBJECTIVE
   ↓
ACTIVITY
   ↓
EVIDENCE OF LEARNING
   ↓
ASSESSMENT
```
اگر Objective چیز دیگری باشد ولی Activity چیز دیگری را تمرین کند، Lesson Plan از نظر آموزشی misaligned است.
### 5. Lesson Plan حرفه‌ای فقط «چه کار کنیم؟» نیست

یک Plan معمولی می‌گوید:

> 10 min — Students do exercise 3.

اما Plan حرفه‌ای می‌گوید:
```
Why?
What exactly happens?
What does the teacher do?
What do students do?
What interaction pattern is used?
What evidence of learning are we looking for?
What problems might occur?
What happens next?
```
یعنی هر Stage باید Pedagogical Logic داشته باشد.

### 6. Lesson Staging

یک Lesson معمولاً از چند Stage تشکیل می‌شود.

یک مدل بسیار کاربردی:
```
ENGAGE
  ↓
EXPOSE
  ↓
NOTICE
  ↓
CLARIFY
  ↓
PRACTISE
  ↓
USE
  ↓
PRODUCE
  ↓
ASSESS
  ↓
FEEDBACK
```
البته این Sequence بسته به نوع درس تغییر می‌کند.

مثلاً:

#### Grammar Lesson
```
Context
→ Exposure
→ Meaning
→ Form
→ Pronunciation
→ Controlled Practice
→ Guided Practice
→ Freer Practice
→ Production
→ Feedback
```
#### Reading Lesson
```
Pre-reading
→ Prediction
→ Gist Reading
→ Detailed Reading
→ Language / Text Analysis
→ Post-reading
→ Personal Response
```
#### Listening Lesson
```
Pre-listening
→ Prediction
→ First Listening / Gist
→ Second Listening / Detail
→ Language Analysis
→ Response / Discussion
```
### 7. Teacher Activity ≠ Student Learning
این نکته خیلی مهم است.

اینکه معلم خوب توضیح بدهد، الزاماً به این معنی نیست که زبان‌آموز یاد گرفته است.

بنابراین باید دائماً این سؤال را بپرسیم:

> What are the students actually doing?

نه فقط:

> What is the teacher doing?

مثلاً:

❌ Teacher explains Present Perfect for 10 minutes.

بهتر:

✅ Students examine examples, identify the meaning, compare them with Past Simple, formulate a rule, test the rule, and then use the structure in a communicative task.

اینجا learning activity اتفاق افتاده، نه صرفاً teacher activity.

### 8. Interaction Pattern

Lesson Plan حرفه‌ای باید Interaction را نیز طراحی کند:
```
T → Ss     Teacher → Students
T ↔ S      Teacher ↔ Student
S ↔ S      Student ↔ Student
S ↔ Ss     Student → Students
Ss ↔ Ss    Students ↔ Students
S          Individual work
```
این موضوع مهم است چون اگر تمام Lesson به شکل:

> Teacher → Students

باشد، Student Talking Time پایین می‌آید.

### 9. Timing

زمان‌بندی فقط جمع کردن دقیقه‌ها نیست.

باید بدانیم:

هر دقیقه چه ارزش آموزشی ایجاد می‌کند؟

مثلاً:
```
Stage	Time	Purpose
Lead-in	5 min	Activate schema
Exposure	7 min	Establish context
Clarification	8 min	Build understanding
Controlled Practice	8 min	Accuracy
Guided Practice	7 min	Controlled transfer
Communicative Task	10 min	Fluency / meaningful use
Feedback	5 min	Consolidation
```

### 10. Anticipated Problems

یک Teacher حرفه‌ای قبل از کلاس فکر می‌کند:

#### Language Problems
```
Meaning confusion
Form errors
Pronunciation problems
L1 interference
Incorrect word choice
Misuse of tense/aspect
```
#### Classroom Problems
```
Students finish early
Students cannot understand instructions
Unequal participation
Weak students remain silent
Strong students dominate
Activity takes longer than expected
```
و برای هرکدام:

> Problem → Cause → Preventive Action → Backup Solution

### 11. Assessment در Lesson Plan

Assessment نباید فقط یک امتحان آخر کلاس باشد.

در واقع می‌توانیم داشته باشیم:

#### Diagnostic Assessment

قبل از تدریس:

#### What do students already know?

>Formative Assessment

در طول درس:

>Are students learning?

#### Summative / Outcome Check

در پایان:

> Can students actually do what the objective said?

### 12. Lesson Plan واقعی = Decision-Making System

این بخش خیلی مهم است.

یک Lesson Plan خوب fixed script نیست.

بلکه یک decision-making framework است.

مثلاً:
```
IF students understand quickly
        ↓
    move forward

IF students struggle
        ↓
    clarify / model / scaffold

IF activity is too easy
        ↓
    increase challenge

IF activity is too difficult
        ↓
    add support
```
پس Teacher نباید برده‌ی Lesson Plan باشد.

>Lesson Plan باید به Teacher کمک کند تصمیم بهتر بگیرد.

### 13. بهترین تعریف حرفه‌ای

اگر بخواهم همه‌ی این‌ها را در یک تعریف فشرده جمع کنم:

>A professional lesson plan is a pedagogically aligned, learner-centred blueprint that connects learning needs and objectives to a carefully sequenced set of learning experiences, teacher and learner actions, interaction patterns, assessment opportunities, feedback, and evidence of learning within a defined time and context.

و به زبان خیلی ساده:

>Lesson Plan یعنی طراحی مسیر یادگیری؛ نه طراحی فعالیت.

### 14. و برای پروژه‌ی خودمان یک نکته‌ی خیلی مهم

برای American English File 4 که داریم Lesson Planهایش را مرحله‌به‌مرحله طراحی می‌کنیم، بهتر است صرفاً به ساختار کتاب اکتفا نکنیم.

یعنی:
```
BOOK CONTENT
      ↓
LESSON OBJECTIVES
      ↓
LEARNING ARCHITECTURE
      ↓
TEACHING PROCEDURES
      ↓
LEARNER ACTIONS
      ↓
ASSESSMENT
      ↓
TRANSFER
```
بنابراین STEP 1, STEP 2, STEP 3... که برای Unit 4A و 4B ساخته‌ایم، در واقع می‌تواند تبدیل شود به یک Professional Lesson-Planning System؛ یعنی سیستمی که فقط برای یک درس نیست، بلکه بعداً بتوانی برای هر Unit، هر Coursebook و حتی Lessonهای مستقل از آن استفاده کنی.

اصل طلایی:
-
> **Don't plan what the teacher will teach. Plan how the learner will learn. 🎯**
